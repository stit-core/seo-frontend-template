Пол JS: одинаковая контентная страница

Эта страница существует только ради измерения: сколько байт HTML, JS и CSS фреймворк отдаёт за статический контент без интерактива.

Разметка одинакова во всех сборках: один заголовок первого уровня, три абзаца, список из пяти ссылок и одна растровая картинка с явными размерами.

Ничего не гидрируется, ни один обработчик событий не навешан. Всё, что приезжает в браузер сверх HTML, — это цена самого фреймворка.
