# routing

## Как устроены маршруты

| поле | значение |
|---|---|
| источник | файлы `src/pages` — 1 файл = 1 URL; подпапки = сегменты URL |
| параметрические | `[slug].astro` + `getStaticPaths()` из контента |
| файлы страниц | `src/pages/_<name>/` — разметка и модель страницы, префикс `_` вне роутинга |
| формат сборки | `build.format: 'directory'` → `/about/index.html`, адрес без `.html` |
| хвостовой слеш | без слеша (`TRAILING_SLASH`, `shared/redirects/table.ts` — его же получает `trailingSlash` Astro): `/blog/` → 301 `/blog` |
| регистр | не нормализуется — URL к нему чувствительны, canonical = реальный адрес |

## Локали в URL

| locale | префикс | пример |
|---|---|---|
| `ru` | нет (дефолтная) | `/blog/<slug>` |
| `en` | `/en` | `/en/blog/<slug>` |

Локаль — строка дескриптора `src/shared/i18n/locale.ts` (первая — без префикса); страница — один файл маршрута
на все локали (`src/pages/[...locale]/…`), её языки — версии карты сайта strategy.
Авторедиректов по `Accept-Language` нет — язык выбирает человек ссылкой в шапке.

## Карта страниц

Перечень — из `pages.md` FSD-карты поверхности (`<strategy-path>/docs/projects/<slug>/fsd/<surface>/`).
Режим и заголовки кеша каждой строки — в `rendering.md`; здесь только адреса и происхождение.

| путь | происхождение | локали |
|---|---|---|
| `/` | `src/pages/[...locale]/index.astro` | `ru`, `en` |
| `/blog`, `/blog/page/N`, `/blog/<slug>`, `/blog/tag/<tag>` | коллекция `post` | `ru`, `en` |
| `/about`, `/contacts`, `/contacts/spasibo` | статические страницы | `ru`, `en` |
| `/legal/privacy` | статическая страница | `ru` |
| _<path>_ | _файл или коллекция_ | _локали_ |

## Редиректы и нештатные коды

| ситуация | ответ | где |
|---|---|---|
| переезд URL | `301` (или `308`, если метод обязан сохраниться) — один хоп с любой формы старого адреса | `content/redirects.yaml` → обёртка процесса `docker/server.mjs` |
| неканоническая форма своего адреса (слеш, `//`, `/index.html`, точки) | `301` на канонический адрес; `%2F` в пути и заглавные — `404` | обёртка процесса, канон пути `shared/redirects` |
| удалено навсегда | `410` + `noindex`, на языке префикса пути | `content/redirects.yaml` → `app/middleware` |
| путь без файла | `404` + `noindex`, на языке префикса пути | `src/pages/404.astro` (on-demand) |
| ошибка рендера on-demand | `500` + `noindex`, дефолтная локаль | `src/pages/500.astro` |

Редиректы — данные, один хоп, без цепочек; `meta refresh` и `redirects` в
`astro.config.ts` не используются. `from` — адрес старого сайта как он был: заглавные, кириллица,
хвостовой слеш, `?query` (`/?p=123`, `/index.php?id=5`). Дубля страницы по другой форме адреса
нет: с неё процесс отвечает одним 301, edge путь не переписывает.

## Навигация

| элемент | что в нём |
|---|---|
| шапка | _пункты меню_ + переключатель локали и темы |
| подвал | _ссылки_ + политика ПДн, RSS |
| хлебные крошки | вложенные страницы: один массив в `<Breadcrumbs>` и в `breadcrumbList()` |

## Generates

- `src/pages/**` — файлы маршрутов и `getStaticPaths()`
- `src/pages/_<name>/` — файлы страниц: разметка, общая для локалей, и модель
- `content/redirects.yaml`
- строки в `rendering.md § Карта маршрутов`; карту сайта пишет сборка по страницам `dist/client`
- `src/shared/i18n/dict.ts` — подписи навигации
