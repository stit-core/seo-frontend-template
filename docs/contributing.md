# Устройство `.claude`-системы

Агент-инфраструктура репозитория: правила, процедуры и план. Наследуется форком —
`/de-template` её не удаляет, ради неё форк и берут.

Вклад в сам шаблон (issue, PR, стиль коммитов) — `CONTRIBUTING.md` в корне.

## Структура

```
.claude/
├─ rules/            # правила: подгружаются по `paths`, когда агент читает файл темы
├─ skills/           # процедуры: smartdev, plan, init-service, stack-deep-dive,
│                    #   de-template, scaffold, content, seo-audit, release
├─ plans/           # активные планы <slug>.md и backlog.md (skill /plan)
└─ settings.json     # настройки сессии (permissions)
```

## Правила

`.claude/rules/<topic>.md` — инварианты с фронтматтером `description` + `paths` (из
фронтматтера Claude Code читает только `paths`). Правило подключается автоматически, когда
агент читает файл под его `paths`: открыл `src/pages/**` — приезжает `render-safety`, запись
коллекции — `content-invariants`. Правило без `paths` (`forward-only`) загружается всегда,
как `CLAUDE.md`.

| правило | о чём |
|---|---|
| `fsd-architecture` | слои, навязанные Astro entry, public API, server-only |
| `content-invariants` | frontmatter и бюджеты, один h1, черновики, переводы, редиректы как данные |
| `render-safety` | три момента исполнения: сборка · запрос · остров |
| `seo-invariants` | head через layout, hreflang, JSON-LD, robots/sitemap/фиды, гейты |
| `forms-antispam` | форма без JS, антиспам-лестница, согласие на ПДн, доставка |
| `shared-ui` | токен-слой, тема, картинки, 0 JS по умолчанию |
| `env-local` | env только runtime, `SITE_URL` и штамповка, whitelist в HTML, секреты |
| `tests-pipeline` | два проекта Vitest, Container API, axe, Playwright, состав гейта |
| `comments` | комментарии только про «зачем», по-русски |
| `forward-only` | тексты описывают текущее состояние, история — в `git log` |

Правило — это то, что **обязано выполняться**; объяснения и карты — в `docs/`.

## Скиллы

Каждый скилл — папка с `SKILL.md` (фронтматтер `name`/`description` + процедура) и
опциональными подкаталогами:

- `references/` — статичные документы процедуры (чек-листы, prune-листы, скелеты файлов);
- `state/` — рабочая память сессии (открытые вопросы, прогресс волн). **Коммитится**:
  это общая проектная память между сессиями и участниками.

Хороший скилл — короткая однозначная процедура с проверяемым результатом: гейт на входе,
шаги, гейт на выходе. Не эссе и не пересказ документации — на неё он ссылается.

## Планы

Содержательное изменение идёт через план — файл `.claude/plans/<slug>.md` (скилл `/plan`):
критерии приёмки, шаги с проверками и «Где мы сейчас» — план переживает `/clear` и виден
остальным. Закрытый план **удаляется целиком** — история в `git log`; незакрытый хвост —
строкой в `.claude/plans/backlog.md`. Формат проверяет `pnpm plan:check`.

## Память

Авто-память не используется: долгосрочное знание живёт в репозитории — `CLAUDE.md` (ядро и
роутер), `.claude/rules/`, `state/` скиллов, `docs/`.

## Forward-only

Всё в `.claude/` описывает текущее состояние: без журналов прошлого, без «было/стало»,
без пометок «устарело». Факт, вынесенный эволюцией, удаляется вместе с упоминанием.

## Как менять

Правки `SKILL.md` и правил идут через `/plan` — план в `.claude/plans/`, чтобы изменение
пережило `/clear` и было видно остальным. Новое правило границ FSD — ещё и негативная
фикстура в `.gate-fixtures/` со строкой в `expected.json`: правило, которое не валит
гейт, не существует.
