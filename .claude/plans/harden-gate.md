# harden-gate — страховочная сетка: гейт ловит поломки, тесты держат страницы, хуки не обходятся

## Цель
Первая фаза программы `audit-program` (P1). Сейчас `pnpm check` ловит 24 из 45 реалистичных поломок эталона,
11 из 27 типовых нарушений агента и ни одного из шести SEO-нарушений; покрытие не считается, страницы и
служебные маршруты не тестируются, собственные скрипты гейта не защищены, pre-push обходится. После фазы
машина держит то, что обещают правила, — на этом фундаменте идут все следующие фазы.

## Не входит
- Правки `docker/*`, CSP, `/_image`, стек — P2 (здесь только тесты существующего поведения).
- Смена механизмов SEO и GEO (карта из сборки, сущность с `@id`, политика ИИ-ботов) — P3; здесь гейт ловит их
  нарушения на текущем коде.
- Ворота strategy (`page_gates.py` и цепочка) в `/release` — P8; здесь — дешёвые статические зеркала в гейте.
- Маршрут задачи в CLAUDE.md и доставка обновлений в форки — P9.

## Решения
- Покрытие считает сам `pnpm test` (`vitest run --coverage`), скрипт `test:coverage` удалён — один способ;
  точечный `pnpm vitest run <путь>` идёт без порогов. Отчёт — `text` со `skipFull`: в выводе гейта только файлы с
  дырами и сводка, html и json не пишутся.
- Пороги — храповик по всем четырём метрикам: факт, округлённый вниз, поднимается тем же коммитом, что поднял
  покрытие (S2–S4), — иначе удалённый тест или непокрытая страница не роняют гейт, пока факт выше пола.
- Тесты маршрутов импортируют модули статически: `vi.mock('astro:content')` Vitest поднимает выше импортов, а
  фикстуры отдаёт фабрика мока (`import('./fixtures')`) — без `no-unsafe-*` прототипов аудита. `getStaticPaths`
  обёртки достаётся приведением модуля к `DynamicRoute`: `src/env.d.ts` объявляет у `.astro` только `default`.
- Логика секций блога — `_blog/sections.ts`, а не `model.ts`: файл `model` Steiger читает сегментом, `_blog`
  становится слайсом, и `./_blog/feed` из `rss.xml.ts` — обход public API. MUT-03, 09, 21, 23 перенесены туда же
  с той же семантикой (`M/tests/mutations.py`; исходная версия — `mutations.audit.py`).
- В фикстурах четыре заметки: у русского блога две страницы списка, у английского одна — пагинация и ссылка на
  перевод страницы 2 (MUT-21) проверяются на реальном случае, а не на синтетическом `Page`.
