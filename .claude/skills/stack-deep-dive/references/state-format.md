# Формат заметки `state/<kind>.md`

Память скилла — рабочее состояние знания о платформенном артефакте. **Не журнал.**

Лежит рядом со скиллом (`.claude/skills/stack-deep-dive/state/`) и **коммитится** —
общая проектная память между сессиями и архитекторами. Не часть артефактного канона
`docs/stack/` (туда уходят зафиксированные решения). Forward-only: только текущее
открытое, без «было/стало» и без дат сессий. Это держит `git log` чистым — коммиты в
state маленькие и тематические («закрыл blocker про источник контента»).

Артефакты — singleton'ы на kind, поэтому путь плоский: `state/<kind>.md`, без вложений.

## Шаблон

```markdown
---
kind: content
ref: docs/stack/content.md
---

## Открытые вопросы
- Тексты услуг ведёт маркетолог без git — тогда коллекция `service` не может быть
  `static`; нужен либо PR-процесс, либо CMS. (**blocker**)
- Нужен ли `en` для раздела вакансий, или он только `ru`?

## Платформенные решения
- Обложки записей — мастер 1600×900 рядом с текстом: из одной картинки сборка делает и
  карточку, и превью ссылки `og:image`.

## Что копать дальше
- После ответа про маркетолога — свести режимы коллекций в `rendering.md`.
```

## Frontmatter

| ключ | значение | назначение |
|---|---|---|
| `kind` | один из kinds каталога `docs/stack/README.md` | подсказка |
| `ref` | путь к артефакту от корня репо | удобная ссылка в редакторе |

## Секции

Все три опциональны.

### `## Открытые вопросы`

Список незакрытых смысловых вопросов, каждый — одна строка.

- Префикс `**blocker:**` или суффикс `(**blocker**)` — блокирует `stable`.
- Закрытый вопрос **удаляется** (не зачёркивается). Пусто → удалить секцию.
- Формулировка проверяемая. Хорошо: «Кто правит тексты услуг — разработчик или
  маркетолог?». Плохо: «разобраться с контентом».
- **Cross-kind blocker** — частый случай: писать в state того роллапа, который
  недополучил. `state/config.md` → «`api` объявил `SMTP_URL` — добавить в таблицу
  (**blocker**)»; `state/rendering.md` → «страница `/services` из карты без режима».

### `## Платформенные решения`

Неочевидные решения, не влезшие в артефакт по форме.

- Одна строка = одно решение, форма «<что выбрано> — <почему>».
- Решение, растворившееся в самом артефакте, отсюда удаляется.

### `## Что копать дальше`

Локальные следующие шаги. Шаг — задача, вопрос — неясный смысл; не путать.
Выполнен — строка удаляется. Пусто → удалить секцию.

## Жизненный цикл

- **Создаётся** только когда есть что записать.
- **Перезаписывается** свободно.
- **Удаляется**: все секции пусты; либо артефакт промоутнут в `stable` без blocker'ов
  и в заметке не осталось непустых `## Платформенные решения`.

## Что НЕ хранить

- Историю изменений — это `git log`.
- Журнал сессий «над чем работали такого-то числа».
- Дубликаты содержимого артефакта (имена env, версии — они в самом файле).
- Общие рекомендации модели «обычно делают так» — это не решение архитектора.
